行迹

把一次旅行，拆成六个可核验的步骤

需求理解 → 资料检索 → 天气适配 → 地点核验 → 路线编排 → 预算计算。每一步都会留下结果与来源，而不是只给一段无法验证的文案。

01

先澄清，再规划

日期、天数、预算口径冲突时先提问，不把推测写成你的偏好。

02

地点必须核验

编排只使用通过核验的地点；必去地点无法匹配时会明确告知。

03

天气真的会改行程

降水或高温时优先室内景点，并记录替换过程。

04

预算透明可解释

分项估算、人均/总额口径、超支建议全部可见。

05

支持 Word 与 PDF

导出 .docx、.doc 与 PDF，包含来源、假设与风险提示。

06

没有 Key 也能跑

演示模式明确标注示例数据，不伪装成实时结果。
