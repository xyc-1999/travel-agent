## 2. 天气：和风 3 天预报

| 日期 | 天气 | 温度 | 降水概率 | 来源 |
| --- | --- | --- | --- | --- |
| 11-05 | 阴 | 15~21℃ | 20% | `qweather_forecast` |
| 11-06 | 多云 | 15~21℃ | 20% | `qweather_forecast` |
| 11-07 | 小雨 | 14~18℃ | 80% | `qweather_forecast` |

结果：

- 三天 `is_forecast=true`；
- 11-07 被判定为不适合长时间户外，天气适配记录“1 天不适合长时间户外”；
- 行程生成成功，3 天结构完整。

说明：

- 和风免费接口只提供 3 天预报，超出范围会回退历史气候参考，这是设计行为；
- 天气请求使用本地城市坐标表，不依赖 GeoAPI，避免凭据的 API 限制导致城市搜索被拒。

## 4. 对照结果

| 场景 | 地点来源 | 天气来源 |

## 5. 已知限制

- 本次只验证了未来 3 天内的日期；
- 未验证高德营业时间、票价、实时路况或驾车路线；
- 未验证和风预警、空气质量等未使用的接口；
- 真实 Key 的额度、限流与欠费状态由外部平台决定，应用只做失败回退并保留数据来源标注。

## 6. 复现方式

1. 在项目根目录 `.env` 配置：

   ```ini
   AMAP_API_KEY=...
   QWEATHER_API_KEY=...
   QWEATHER_API_HOST=https://<你的 API Host>
   ```

2. 启动服务：

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
   ```

3. 检查 Provider：

   ```powershell
   Invoke-RestMethod http://127.0.0.1:8765/api/health | ConvertTo-Json
   ```

4. 页面中选择未来 3 天内的日期：成都用于验证天气，青岛用于验证地图。天气场景保持“自动”。
